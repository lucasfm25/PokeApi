# PokeAPI Hub

Projeto desenvolvido em FastAPI para estudo de consumo de APIs REST e organização em camadas.

## Tecnologias

- FastAPI
- uv
- Jinja2
- HTML
- CSS
- JavaScript

## Funcionalidades

- Listagem de Pokémon
- Pesquisa de Pokémon
- Pesquisa de Shiny
- Linha Evolutiva
- Pesquisa por Região
- Pokédex por Região
- Pesquisa de Moves
- Pesquisa de Moves por Pokémon
- Listagem de Berries
- ...
